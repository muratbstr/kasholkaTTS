# История изменений kasholkaTTS

Текущая версия — **1.5.0 Release 1**, сборка **18**.
Отдельная экспериментальная ветка: [1.5.1 Beta 1](beta/CHANGELOG.md), сборка **19**.
Обход Юрия из 1.4.3 остаётся отменённым. Ниже приведена история в обратном порядке выпуска;
возврат к 1.4.2 указан отдельно от первоначальной версии 1.4.2.

## 1.5.0 Release 1 — 2026-10-24

- Добавлен выбор формата и качества экспорта: M4A (AAC 64/128/192 кбит/с), WAV (PCM 16/24 бит), исходный AIFF/CAF. Имя и папка выбираются в окне сохранения; формат/качество запоминаются.
- Преобразование выполняется в фоне системным `afconvert` и отменяется кнопкой «Стоп». Старый файл заменяется только после успешного завершения всей операции.
- Добавлена кнопка «Прослушать»: короткая фраза выбранным голосом с текущей скоростью и высотой, без изменения текста и выделения. Поддержаны пауза, остановка и все существующие речевые движки.
- Добавлены проверки отмены/ошибок преобразования, сохранности редактора при прослушивании и нативный тест форматов для Mac. Реальные кодеки и интерфейс на Windows не проверяются.

## 1.4.6 Release 1 — 2026-10-24

- Подпись в About обновлена на `coded by gpt-6 astra (vs code + codex)`.
- Полоса прогресса полностью удалена из экрана запуска; сохранены текст этапов, версия и минимальная длительность показа в одну секунду.
- Плашка версии в About сдвинута ближе к правому нижнему углу: отступы по 12 пикселей, текст выровнен вправо.

## 1.4.5 Release 1 — 2026-10-24

- Карточка About перенесена в центр окна и сделана стеклянной: полупрозрачный материал с размытием и светлой обводкой, непрозрачные надписи поверх.
- Плашка версии перемещена в правый нижний угол About.
- Серый системный индикатор на экране запуска заменён белой полосой с полупрозрачной дорожкой; цвет не зависит от активности окна и системного оттенка.

## 1.4.4 Release 1 — 2026-10-24

- Полностью обновлено оформление About: видео на весь фон, прозрачная верхняя панель окна, скруглённая карточка с размытием, крупное название и отдельная плашка версии.
- Добавлены подписи `coded by gpt-6 astra (codex)` и `prompting by strch` вместо прежней авторской строки.
- Добавлен экран запуска на основе пользовательского `ktts_loading_osn.png` с версией слева внизу, ровно выровненными этапами и индикатором прогресса.
- Подготовка интерфейса, загрузка голосов и применение настроек выполняются по этапам. Экран показывается минимум одну секунду, при более долгой подготовке — до её окончания, без блокирующей паузы.
- Список голосов разделён по языкам и регионам; известные шуточные голоса находятся в подразделах «Забавные». Добавлены разделители, убраны номера и коды локалей из строк голосов.
- Сохранены выбор голоса, пункты с одинаковыми именами и отметки Siri. Голоса не переименовываются и не добавляются искусственно.
- Фон загрузки включён в установщик; исходные изображения не изменены.

Проверки логики и упаковки выполняются на Windows. Нативные эффекты About,
отображение запуска и выбор пунктов нового меню требуют проверки на Monterey.
Известное смещение подсветки Юрия в этой версии не исправлялось.

## 1.4.2 Release 1 — группировка по языкам

- Список голосов разделён невыбираемыми заголовками языков. Русский раздел расположен первым.
- Региональные варианты одного языка объединены в общий раздел; локаль каждого голоса остаётся видна.
- Сохранены отметки `[Siri]`, выбор голоса после обновления списка и отдельные пункты для голосов с одинаковыми именами.
- Голоса без указанной локали помещены в раздел «Язык не указан».
- Выполнен возврат к поведению 1.4.2: переключение Юрия на AVFoundation из 1.4.3 отменено.
- Установщик выпускается как `kasholkaTTS-1.4.2-Release-1-languages-macOS-installer.zip`. Исходный архив 1.4.2 сохранён отдельно.
- Добавлен этот CHANGELOG; он включён в архив установщика и связан с README.

Известные ограничения: подсветка Юрия через классический движок может смещаться.
Группировка проверена в тестовой модели; её отображение в настоящем AppKit требует проверки на Mac.

## 1.4.3 Release 1 — изменения отменены

- Добавлена попытка читать голосом Юрий через AVFoundation, только при доступности того же идентификатора голоса.
- Для AVFoundation отключено выравнивание диапазонов по соседним словам.
- Сохранение Юрия в AIFF оставлено через классический движок, без зависимости от Swift.
- При недоступности AV-варианта сохранялся прежний движок с сообщением о возможном смещении подсветки.

Обход прошёл проверки логики на Windows, но исправление подсветки на Monterey не было подтверждено.
По решению пользователя текущая сборка вернулась к 1.4.2.

## 1.4.2 Release 1 — первоначальная диагностическая сборка

- Добавлено меню **Дебаг → Диагностика подсветки…**.
- Запись включается вручную на одно чтение и ограничена первыми 80 событиями.
- Отчёт содержит голос, параметры, исходные и отображаемые диапазоны, смещение выделения и короткие фрагменты текста.
- Отчёт хранится в памяти до выхода; копирование выполняется отдельной командой пользователя.

Полученный отчёт с macOS 12.6.5 показал неверные диапазоны у Юрия через
`NSSpeechSynthesizer` при совпадающем исходном тексте и тексте обратного вызова.
Эта версия добавила диагностику, но не устранила смещение.

## 1.4.1 Release 1

- Добавлено выравнивание частично смещённых диапазонов по границам слов русского и латинского текста.
- Сохранены точные диапазоны нескольких слов, обработка выделенного фрагмента и позиции UTF-16.
- Добавлены проверки пунктуации, эмодзи, составных слов и смещения диапазона на один символ.

Поправка исправляла искусственно воспроизведённые случаи, но пользователь подтвердил
сохраняющееся смещение на «чтения, подсветки» у Юрия.

## 1.4.0 Release 1

- Добавлена подсветка текущего слова по событиям речевого движка, включая чтение выделенного фрагмента.
- Добавлена отключаемая автопрокрутка через меню **Вид**; её состояние запоминается.
- Вертикальная полоса прокрутки сделана постоянно доступной.
- Добавлены команды **Файл → Открыть текст… (⌘O)** и **Сохранить речь в аудиофайл… (⌘S)**.
- Добавлен экспорт всего текста или выделения с выбранным голосом и параметрами: AIFF через классический движок, CAF через Swift-помощник для AVFoundation.
- Добавлена отмена экспорта кнопкой «Стоп». Существующий файл заменяется только после успешного синтеза.
- В архив включён длинный тестовый файл `samples/kasholkaTTS-long-test.txt` с описанием программы, русским и английским текстом, числами и эмодзи.

Для CAF нужны уже установленные Apple Command Line Tools или Xcode.

## 1.3.0 Release 1

## 1.1.1

- Исправлена загрузка классов AVFoundation, включая `AVQueuePlayer`, через загрузку framework и Objective-C runtime.
- При ошибке видео About открывается с текстом; причина выводится в строке состояния.

- Сохранён обычный вид ползунка скорости, без черепахи и зайца.
- Регулятор высоты временно удалён; прежние сохранённые значения не применяются.

## 1.1.0

- Добавлена зелёная иконка с силуэтом и скруглёнными углами; внутренние пятна и прозрачные участки удалены программно.
- Добавлено окно About с названием, версией, подписью `vibecoded by strch` и фоновым видео.

## 1.0.1

## 1.0.0

- Первый выпуск читалки для macOS Monterey 12 и новее.
- Добавлены системные голоса, чтение всего текста или выделения, скорость и экспериментальная высота речи.

- Подготовлен ZIP-установщик `.command`, собирающий приложение на Mac штатными средствами и устанавливающий его в `~/Applications`.

## Проверки и ограничения

Проверки логики и упаковки на Windows не заменяют запуск AppKit, JXA и речевых
движков на Mac. Экспериментальный поиск не гарантирует доступность Siri.
Чек-лист проверки находится в [tests/MAC_SMOKE_TEST.md](tests/MAC_SMOKE_TEST.md)
или в `MAC_SMOKE_TEST.txt` внутри архива установщика.

- Ошибки установки показывают путь к техническому журналу; успешная установка удаляет журнал. Сохранены проверки пути, резервное копирование и установка без пароля администратора.
- Документация объединена с ручными изменениями на GitHub: сохранены MIT-лицензия, GIF-инструкция по установке голосов, авторство и оформление. Добавлен динамический счётчик скачанных файлов.

Первый переход с 1.5.x требует ручной установки. Проверки на Windows не заменяют проверку интерфейса, речи и установки на Mac. Siri по-прежнему не гарантированы; известное смещение подсветки у Юрия остаётся.
