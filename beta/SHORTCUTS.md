# Siri через «Команды» — Beta 1.8.1

Этот режим проверяет возможность чтения выбранным голосом через приложение Apple «Команды» на macOS Monterey 12 и новее. Наличие Siri и его фактическое звучание на Monterey 12.6.5 пока не подтверждены. Новый способ не добавляет голос в обычный список и не даёт приложению управление высотой, скоростью или экспортом этого чтения.

## Настройка один раз на Mac

1. Откройте **«Команды» / Shortcuts** и создайте команду **kasholkaTTS Siri**.
2. Добавьте **«Получить текст из входных данных» / Get Text from Input**. В качестве входа укажите переменную **«Входные данные команды» / Shortcut Input**. Beta передаёт файл TXT, а это действие извлекает его содержимое.
3. Добавьте **«Произнести текст» / Speak Text**. Подставьте результат первого действия. Раскройте параметры действия, выберите язык и голос Siri, если он доступен, и нужную скорость. Названия локализованных действий могут немного отличаться.
4. В Beta вставьте короткий тестовый текст. Откройте **Beta → Siri через «Команды»…**. Этот режим также доступен через окно поиска Siri → **Команды macOS → Настроить запуск**.
5. Нажмите **«Обновить список»**, выберите свою команду и нажмите **«Запустить команду»**. При необходимости ответьте на системные запросы в приложении «Команды».
6. Сравните звучание с системной пробой Siri. Если в «Командах» Siri отсутствует или заменяется обычным голосом, этот способ не обходит ограничение на данном Mac.

Произносится выделенный фрагмент; если выделения нет — весь текст. Создавать команду заново для каждого запуска не нужно. Её имя запоминается в настройках Beta. Запуск выполняет все действия выбранной команды: используйте свою отдельную команду только для чтения. Получение списка само по себе ни одну команду не запускает.

## Закрытие и остановка

Закрытие окна оставляет ожидание в фоне. **«Прервать ожидание»** и основная кнопка **«Стоп»** завершают только процесс запуска, которым владеет Beta. Уже выполняющееся действие в приложении «Команды» может продолжиться: остановите команду там. То же ограничение действует при выходе из Beta. Пауза и подсветка текста в этом режиме недоступны.

Получение списка ограничено 20 секундами. Выполнение команды не ограничено коротким тайм-аутом: длинный текст может читаться долго, а системный запрос — ждать ответа. Если ничего не происходит, откройте «Команды», проверьте настройку и запросы разрешений; при необходимости прервите ожидание.

## Данные и диагностика

Текст записывается в отдельную временную папку с правами 0700 и передаётся через `shortcuts run <имя> --input-path <файл>`, без shell. Beta удаляет свои временные файлы после завершения или отмены; после аварии они могут остаться. Сама выбранная команда определяет, что делает с полученным текстом.

Во вкладке **Диагностика → Эксперименты** записываются состояние, код выхода и число команд. Имена команд, текст редактора и сырой вывод ошибок Shortcuts в копируемый отчёт не включаются. Код 0 означает завершение команды, а не подтверждение Siri.

Если есть команды с одинаковыми именами, переименуйте их и обновите список. Имя выбранной команды не должно начинаться с дефиса или содержать управляющие символы. При отсутствии `/usr/bin/shortcuts` установка сторонних инструментов автоматически не запускается.

[Apple: запуск «Команд» с входными файлами из командной строки](https://support.apple.com/en-au/guide/shortcuts-mac/-apd455c82f02/mac).

## Проверка на Monterey 12.6.5

- Список пустой и непустой, команда удалена/переименована после получения списка.
- Имя с пробелами и кириллицей, русский текст с emoji, выделение и весь текст.
- Голоса ru-RU, en-US, en-GB: доступность внутри действия и сравнение звука с системной пробой.
- Успех, отказ в разрешении, неверно настроенная команда, долгий запрос подтверждения.
- Закрытие/повторное открытие, «Прервать ожидание», «Стоп», выход из Beta: отслеживать отдельно процесс запуска и продолжающуюся команду.
- В диагностике нет имени команды и текста. Успешный выход не подписан как «Siri найден».
- Светлая/тёмная темы, русский/английский интерфейс, кнопки выбранного акцента.
