# kasholkaTTS Beta

## 1.5.1 Beta 1 — 2026-10-25

- Создана отдельная версия на базе 1.5.0 Release 1: имя kasholkaTTS Beta,
  bundle ID com.kasholka.tts.beta, сборка 19, независимые настройки и установщик.
- Иконка перекрашена в #0040ff с сохранением силуэта, скруглений и прозрачных углов.
- Добавлен экспериментальный поиск по Siri ID из голосовых настроек и разрешение
  системных голосов по языкам ru-RU, en-US, en-GB в отдельном процессе.
- Добавлены подготовка выделения для системного Spoken Content и проверка say
  без явного выбора голоса. Результат say не выдаётся за подтверждение Siri.
- Добавлен отдельный отчёт экспериментов без текста редактора.
- Стабильная версия 1.5.0 Release 1 остаётся отдельной.
