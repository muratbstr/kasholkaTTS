# История изменений kasholkaTTS

Текущая версия — **1.7.8 Release 3**, сборка **35**.

## 1.7.8 Release 3 — 2026-10-29

- Опубликована основная версия с меню «Вид → Тема»: системная, светлая и тёмная. Выбор сохраняется и применяется без перезапуска.
- Включена поддержка тёмного оформления приложения, редактора и курсора.
- Исправлена передача пустого значения системной темы в AppKit при запуске и переключении: используется Objective-C nil вместо JavaScript null.
- Убраны устаревшие ссылки на удалённую документацию счётчика.
- Новый дизайн Beta в этот выпуск не входит. Нативные проверки на Mac остаются отдельным этапом проверки.


## 1.7.8 Release 2.2 — 2026-10-29

- Исправлена передача пустого значения оформления в AppKit: системная тема использует Objective-C nil через $(), а не JavaScript null. Ошибочный вызов выполнялся при запуске и возврате к системной теме.
- Инициализация темы перенесена внутрь обработчика ошибок запуска, чтобы доступные ошибки показывались пользователю.
- Тесты различают JavaScript null и bridged nil; добавлена проверка пути запуска до экрана загрузки.


## 1.7.6 Release 2.2 — 2026-10-29

- Добавлено меню «Вид → Тема»: системная, светлая и тёмная; выбор применяется сразу и сохраняется.
- Окно, редактор, курсор и стандартные элементы используют адаптивные цвета macOS. Переключение не меняет текст и не прерывает чтение.
- Установщик явно включает поддержку тёмной темы для приложения, собранного через osacompile.
- Из сборщиков убрана ссылка на удалённую документацию счётчика.


## 1.7.4 Release 2.2 — 2026-10-28

- Добавлена поддержка составного обозначения Release (например, 2.2) в проверке обновлений. Первый переход с 1.7.2 требуется выполнить вручную.
- Исправлена проверка обновлений при запуске: убрано ограничение раз в сутки, проверка запускается после экрана загрузки один раз за запуск. Начало и результат видны в строке состояния; отключение автопроверки и ручная команда сохранены.
- Сборщик создаёт отдельные архивы для ручной установки и автообновления, каждый со своей SHA-256. Код приложения и ресурсы в них одинаковы.
- Для ручной установки используется `*-macOS-manual-installer.zip`. Автообновление сохраняет прежнее имя `*-macOS-installer.zip`, ручной ZIP обновлятором не выбирается. Старые стабильные клиенты не распознают Release 2.2: первый переход выполняется вручную.
- Workflow счётчика учитывает только ручные архивы основной версии и Beta. Старые общие ZIP, контрольные суммы, черновики и незавершённые загрузки исключены. Смешанная старая статистика не переносится.
- Добавлены проверки одинакового содержимого двух ZIP, контрольных сумм, воспроизводимости, выбора автоархива и фильтрации счётчика.

Разделение включено в этом выпуске. Исторические скачивания разделить нельзя; прямое ручное скачивание служебного автоархива не учитывается.
