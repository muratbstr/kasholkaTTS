# История изменений kasholkaTTS

Текущая версия — **1.7.2 Release 2**, сборка **26**.

## 1.7.2 Release 2 — 2026-10-28

Изменения с предыдущего публичного выпуска 1.5.0 Release 1:

- Обновления из GitHub: ручная и ежедневная автоматическая проверка, загрузка с проверкой SHA-256, установка и перезапуск. Текст и выделение восстанавливаются после обновления; предыдущая сборка сохраняется для отката. Обычная и Beta-ветки обновляются раздельно.
- Система локализации и английский перевод. Язык выбирается в меню приложения: русский, English или язык macOS; применяется при следующем запуске. Добавлена инструкция для новых переводов.
- Установщик сначала предлагает Русский / English и отмену, затем показывает только шесть этапов установки. Переводы разделены; доступны `--lang ru` / `--lang eng`. Автообновление использует язык приложения без дополнительных диалогов.
- Ошибки установки показывают путь к техническому журналу; успешная установка удаляет журнал. Сохранены проверки пути, резервное копирование и установка без пароля администратора.
- Документация объединена с ручными изменениями на GitHub: сохранены MIT-лицензия, GIF-инструкция по установке голосов, авторство и оформление. Добавлен динамический счётчик скачанных файлов.

Первый переход с 1.5.x требует ручной установки. Проверки на Windows не заменяют проверку интерфейса, речи и установки на Mac. Siri по-прежнему не гарантированы; известное смещение подсветки у Юрия остаётся.
