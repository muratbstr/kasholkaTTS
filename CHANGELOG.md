# История изменений kasholkaTTS

Текущая версия — **1.7.4 Release 2.2**, сборка **29**.

## 1.7.4 Release 2.2 — 2026-10-28

- Добавлена поддержка составного обозначения Release (например, 2.2) в проверке обновлений. Первый переход с 1.7.2 требуется выполнить вручную.
- В Actions → ZIP downloads → Run workflow доступен сброс счётчика. Запоминаются текущие загрузки каждого ручного ZIP; после сброса учитываются только новые.
- Исправлена проверка обновлений при запуске: убрано ограничение раз в сутки, проверка запускается после экрана загрузки один раз за запуск. Начало и результат видны в строке состояния; отключение автопроверки и ручная команда сохранены.
- Сборщик создаёт отдельные архивы для ручной установки и автообновления, каждый со своей SHA-256. Код приложения и ресурсы в них одинаковы.
- Для ручной установки используется `*-macOS-manual-installer.zip`. Автообновление сохраняет прежнее имя `*-macOS-installer.zip`, ручной ZIP обновлятором не выбирается. Старые стабильные клиенты не распознают Release 2.2: первый переход выполняется вручную.
- Workflow счётчика учитывает только ручные архивы основной версии и Beta. Старые общие ZIP, контрольные суммы, черновики и незавершённые загрузки исключены. Смешанная старая статистика не переносится.
- Добавлены проверки одинакового содержимого двух ZIP, контрольных сумм, воспроизводимости, выбора автоархива и фильтрации счётчика.

Разделение включено в этом выпуске. Исторические скачивания разделить нельзя; прямое ручное скачивание служебного автоархива не учитывается.
