# Правила работы с kasholkaTTS

- Публиковать изменения и релизы GitHub только по команде пользователя.
- При команде выпустить версии публиковать обе актуальные ветки: основную и Beta,
  если пользователь явно не ограничил публикацию одной веткой.
- Числовые версии приложения продолжать по принятой схеме. Значения обозначений
  Release и Beta менять только по отдельной команде пользователя. Сейчас: Release 3 и Beta 2.
- Перед публикацией сравнивать GitHub с последним синхронизированным состоянием,
  сохранять ручные правки пользователя и новые файлы; не переписывать историю принудительно.
- Папка «для правок» личная: не читать для других задач, не включать в коммиты,
  архивы исходников, установщики или релизы. Пользовательские заметки не публиковать.
- Для каждого канала публиковать ручной и автоматический ZIP с отдельными SHA-256.
  Пользовательские ссылки направлять на `-macOS-manual-installer.zip`.
- Проверять версии приложения/установщиков/документации, тесты и хеши загруженных assets.
  На Windows не заявлять прохождение нативных тестов macOS.

- По команде пользователя новая числовая ветка Beta начинается с 1.8.0; следующие Beta продолжают эту ветку. По команде пользователя от 2026-10-31 текущее обозначение — Beta 2; сохранять его до следующей отдельной команды.
