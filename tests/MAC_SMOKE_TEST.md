# Проверка kasholkaTTS 1.7.2 Release 1 на Mac

Установщик: при успешной установке только строки `[1/6]` … `[6/6]`, без вывода
osacompile/plutil/codesign и описания инструментов. Проверить `--lang ru`, `--lang eng`,
начальное окно Русский / English / Отмена и финальное окно. Отмена и Esc должны
завершать работу до создания журнала/файлов. При `--lang` выбора нет. В `--update` нет
выбора языка и финального диалога. При неполном ZIP — понятная ошибка и доступный журнал; старая сборка цела.

Для локализации выполнить [чек-лист языков](../docs/LOCALIZATION.md): выбор по macOS,
Русский / English после перезапуска, английские окна/меню/диагностика, сохранность
текста и выбранного голоса. Системные панели могут использовать язык самой macOS.

Полный чек-лист пока не выполнен: среда разработки — Windows. По отчёту пользователя
1.2.2 на Monterey 12.6.5 (21G531) перечисление голосов работает в приложении,
osascript и Swift: каждый способ возвращает 77 голосов, среди них Siri — 0.
Ошибка NSNull устранена. Воспроизведение через Swift этим отчётом не проверено.
Желательно проверить отдельно
на Monterey 12 Intel и Monterey 12 Apple Silicon. Не считать тесты с подменой
Cocoa подтверждением работоспособности UI или настоящего синтезатора.

1. Распаковать новый ZIP штатной «Утилитой архивации». Открыть установщик, проверить
   переход к «Подготовка приложения…» без проверки контроллера JXA,
   отсутствие запроса прав администратора и успешную локальную подпись.
2. Запустить `~/Applications/kasholkaTTS.app`. Проверить русское окно, меню,
   отображение версии 1.7.2 Release 1 в «О kasholkaTTS», светлую/тёмную тему и изменение размера.
   Ошибка `protocol does not exist` не должна появляться.
3. Проверить список голосов, включая голоса с одинаковым именем. Сравнить с
   `/usr/bin/say -v '?'` (голоса Siri могут быть недоступны этому движку).
4. Вставить русский текст с эмодзи через ⌘V. Проверить ⌘A, ⌘C и ⌘Z.
   Прочитать весь текст, затем выделить и прочитать только фрагмент.
5. Проверить пустой текст и выделение из пробелов: воспроизведение не начинается.
6. Во время длинного чтения: пауза, продолжение, стоп, затем немедленный новый старт.
   После завершения кнопки и регуляторы возвращаются в доступное состояние.
7. На одном голосе выполнить подряд несколько полных чтений, меняя скорость
   слева → середина → справа → слева. Каждый раз отпустить бегунок и заново
   нажать «Читать». Повторить для обоих движков. Бегунок не должен прыгать.
   Высоты в окне нет; настройки высоты из предыдущей версии не влияют на голос.
   Проверить сохранение крайнего левого положения после перезапуска.
8. Проверить сброс параметров, смену голоса и сохранение настроек после перезапуска.
9. Открыть UTF-8 и UTF-16 файлы, в том числе по пути с пробелами/кириллицей.
   Отмена диалога должна оставлять текст без изменений.
10. Закрыть окно во время чтения. Убедиться, что звук и процесс завершились.
11. Завершить приложение, повторить установку. Старая версия должна сохраниться
    в `~/Applications/kasholkaTTS-backup.*`, новая — запускаться.
12. При запущенном приложении установщик должен попросить сначала завершить его.
13. Установить без интернета. Прочитать текст уже установленным системным голосом.
14. Проверить отсутствие зачёркнутых заголовков/пояснений, размер окна 760 × 500.
    Уменьшить до минимума, увеличить, проверить отсутствие наложений.
15. Меню «Вид»: 80%, 100%, 150%, ⌘= / ⌘− / ⌘0. Проверить увеличение кнопок,
    шрифта и поля текста, а также сохранение масштаба после перезапуска.
16. Проверить новую иконку в Finder и Dock: скруглённые углы, зелёный фон,
    чёрный силуэт, отсутствие пятен и прозрачных дыр внутри зелёного поля.
17. «О kasholkaTTS»: название, `coded by gpt-6 astra (vs code + codex)`, `prompting by strch`, версия 1.7.2 Release 1,
    видео без звука. Дождаться нескольких повторов. Закрыть/открыть About;
    проверить, что главное окно остаётся открытым, а чтение не прерывается.
    Ошибки `$.AVQueuePlayer.alloc` и `initWithPlayerTemplateItem is not a function`
    не должны появляться. Если видео не удалось
    загрузить, текст About остаётся видимым, причина находится в строке состояния.
18. Проверить дополнительные AVFoundation-голоса, паузу, продолжение, стоп,
    скорость. Если в списке есть **[Siri]**, проверить именно этот голос.
    Если Siri нет, записать версию macOS и названия установленных голосов:
    отсутствие голоса в публичном API нельзя считать успешной поддержкой Siri.
19. После запуска/«Обновить» убедиться, что экспериментальный поиск не начинается.
    Выбрать «Дебаг → Поиск голосов Siri», дождаться фонового поиска (osascript до 15 секунд,
    затем при отсутствии Siri Swift до 60 секунд).
    Проверить, появились ли новые **[Siri]**, записать их названия. Если появились,
    прочитать ими текст, проверить паузу/продолжение, стоп и повторное чтение
    с другой скоростью. При поиске можно печатать, открывать About, читать обычным
    голосом; текущий выбор не должен сбиваться. Ранее выбранный дополнительный
    голос должен восстановиться после следующего запуска и ручного поиска из «Дебаг».
20. Во время чтения дополнительным голосом завершить приложение через ⌘Q,
    затем отдельно проверить закрытие главного окна. Не должно остаться звука
    или процесса `osascript`/`swift-frontend` с аргументом речевого помощника. Проверить аварийное
    закрытие: помощник должен прекратить чтение после истечения 15 секунд.
    Другие процессы osascript не должны затрагиваться.
21. В About проверить отсутствие белых полос между видео и краями области
    содержимого окна. Фигура не растянута, видео обрезается по бокам,
    все надписи остаются поверх видео. Закрытие/повторное открытие сохраняет вид.
22. На Monterey 12.6.5 после проверки Siri открыть «Дебаг → Диагностика голосов…».
    Проверить отчёт для трёх способов; для установленных двух голосов каждого
    языка записать фактические счётчики `en-GB`, `en-US`, `ru-RU` и идентификаторы.
    Кнопка копирования не должна включать текст из редактора.
23. Без выбранных инструментов Apple проверить понятную ошибку Swift и отсутствие
    системного диалога установки. При уже установленных Command Line Tools/Xcode
    проверить список через Swift, затем чтение, скорость, паузу, продолжение,
    стоп и сохранение выбранного Swift-голоса при перезапуске.
24. Проверить, что в отчёте нет `-[NSNull writeToFile:options:error:]`.
    У osascript должен появиться результат реального поиска либо ошибка самого
    запуска; Swift при отсутствии Siri должен запуститься либо сообщить об
    отсутствии инструментов. Старую ошибку подготовки журнала не считать
    результатом проверки доступности Siri. Скопировать новый отчёт целиком.
25. «Дебаг → Высота голоса…»: проверить применение, отмену и сброс для разных
    голосов. После естественного завершения повторить чтение: высота не должна
    накапливаться. На неподдерживаемом голосе отказ не меняет настройку и не мешает
    обычному чтению. Смена голоса сохраняет отдельное значение для каждого голоса
    до выхода, перезапуск возвращает естественную высоту. Проверить сброс через
    главную кнопку «Сброс параметров». Главное окно содержит только скорость.

26. Открыть `samples/kasholkaTTS-long-test.txt` из архива. Прокрутить мышью/трекпадом
    и полосой до последней строки. Повторить в узком окне и при масштабе 150%:
    текст переносится по ширине, конец документа достижим.
27. Читать длинный текст: подсветка следует словам, автопрокрутка сохраняет их
    видимыми. «Вид → Автопрокрутка при чтении» выключает сопровождение, ручная
    прокрутка остаётся свободной. Включение возвращает текущее слово. Проверить
    сохранение переключателя после выхода и обе системные темы оформления.
28. Выделить абзац после эмодзи, читать, поставить на паузу и продолжить. Подсветка
    не смещается, при паузе остаётся, после остановки исчезает. Повторное чтение
    сохраняет исходный фрагмент, если курсор не перемещался вручную. Быстро
    остановить и запустить другой фрагмент: старые события не меняют подсветку.
29. «Файл → Сохранить речь в аудиофайл…» (⌘S): выбрать исходный формат;
    обычный голос пишет AIFF, AVFoundation/голос помощника — CAF через Swift. Проверить текст целиком и
    выделение, скорость, естественную/экспериментальную высоту, имя с кириллицей
    и пробелами. Экспорт не звучит через динамики. Прослушать начало и конец файла
    в QuickTime Player, убедиться в отсутствии обрыва и пустого аудио.
30. Отменить диалог сохранения: чтение не запускается. Отменить длинный экспорт
    кнопкой «Стоп» и через ⌘Q: временный результат убирается, интерфейс разблокирован.
    Взять ненужную копию существующего файла как назначение: при отмене его байты
    остаются прежними; после успешного экспорта он содержит новое аудио.
31. Проверить невозможную запись (папка без прав), недоступный голос и отсутствие
    Swift-инструментов: понятная ошибка, сохранения с другим голосом и автозагрузки
    инструментов нет. Пауза во время экспорта недоступна. После ошибки можно
    снова читать или сохранять. Нативные автотесты: `python3 -m unittest discover -s tests -v`.

32. Голос Юрий: открыть `samples/kasholkaTTS-long-test.txt`, выделить текст от
    «Большой текст» и читать. В заголовке «для проверки чтения» подсветка должна
    показывать целое слово «проверки», затем «чтения», без вида «роверки ч».
    Повторить без выделения и ниже по документу, после эмодзи. Искусственное
    смещение в автоматическом тесте не заменяет эту проверку реального голоса.

33. «Дебаг → Диагностика подсветки… → Записать следующее чтение»: выбрать голос
    Юрий, открыть пример TXT, прочитать от «Большой текст» до «сохранения аудио».
    Нажать «Стоп», снова открыть диагностику и скопировать отчёт. Он должен
    содержать реальные диапазоны и фрагменты, включая «чтения, подсветки».
    Без включения записи отчёт не собирается; после 80 событий запись прекращается.
    Новое обычное чтение не дописывает старый отчёт. Повторное включение очищает его.

34. Список голосов содержит невыбираемые заголовки языков, русский раздел первый.
    Проверить русский, английский и последний раздел; у каждого выбрать голос и
    прочитать текст. Региональные варианты английского находятся в отдельных разделах.
    Обновление списка и перезапуск сохраняют выбранный голос. Совпадающие имена
    остаются разными пунктами; отметки Siri сохранены. После ручного поиска Siri
    новые голоса попадают в соответствующие разделы. Скорость, высота в «Дебаг» и
    экспорт относятся к выбранному голосу, а не к позиции заголовка.
    Версия — 1.7.2 Release 1, Юрий использует NS, обход из 1.4.3 отменён.

35. Запуск: виден предоставленный зелёный фон, версия слева внизу, этапы справа,
    полосы прогресса нет. Быстрый запуск показывает экран минимум секунду; медленный
    не показывает главное окно до окончания подготовки. ⌘Q во время запуска
    завершает приложение без появления главного окна после выхода. Повторное
    открытие работающей программы не запускает splash повторно.
36. About: видео до краёв, прозрачная верхняя панель, кнопка закрытия доступна.
    Стеклянная карточка с размытием и скруглениями находится в центре, через неё
    видно видео, обе подписи читаются. Плашка версии находится в 12 пикселях от
    правого и нижнего края, текст выровнен вправо. Проверить светлую/тёмную
    тему и системное уменьшение прозрачности.
    Закрыть во время речи и открыть повторно: TTS не останавливается, видео продолжается.
37. Проверить разделы английского: Шотландия, Великобритания, США, США — Забавные
    (если соответствующие голоса установлены). Нет номеров/кодов локалей в строках.
    Выбрать голос мышью и клавиатурой после разделителя; проверить название и звук,
    обновление списка, перезапуск, дубликаты имён, паузу и экспорт.

38. «Прослушать» рядом с голосами: проверить с пустым редактором и с выделением
    в длинном документе. Текст, выделение и прокрутка не меняются, подсветка не появляется.
    Русский и английский голоса произносят соответствующие короткие фразы; скорость
    и высота учитываются. Проверить паузу, продолжение, остановку, обычное завершение,
    повторный запуск и дальнейшее чтение текста. Кнопка отключена при чтении и экспорте.
    Проверить все доступные движки, а также минимальное окно при масштабе 80–150%.
39. Экспорт: проверить каждый из пяти профилей M4A/WAV, выбор папки и имени,
    отмену обоих диалогов, запоминание формата/качества и расширение файла.
    Открыть результат в QuickTime, прослушать начало и конец; сравнить темп и голос.
    WAV: PCM 16/24 бит, частота голоса; M4A: AAC, 44,1 кГц, выбранный битрейт
    (при переменном битрейте фактическое среднее значение может отличаться).
    Повторить с обычным голосом и AV/Swift, если он доступен.
40. На длинном экспорте нажать «Стоп» сначала во время синтеза, затем во время
    преобразования. Повторить с выходом через ⌘Q. Старый файл назначения остаётся
    неизменным, частичный результат не публикуется. Проверить недоступную для записи
    папку; после ошибки можно снова читать, прослушивать и экспортировать.
    Автотест реальных кодеков: `python3 -m unittest discover -s tests -p test_audio_conversion.py -v`.

Если запуск не удался: сохранить текст ошибки из окна установщика/приложения,
версию macOS, архитектуру Mac, название голоса и шаг воспроизведения проблемы.

## Обновления

Проверить сценарии из [docs/UPDATES.md](../docs/UPDATES.md): отключённая сеть, каналы, отмена, перезапуск, восстановление текста и резервная копия. На Windows нативный сценарий не проверен.
