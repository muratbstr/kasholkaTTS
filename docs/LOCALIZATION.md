# Языки интерфейса

Начиная с **1.7.0 Release 1 / 1.7.1 Beta 1** доступны русский и английский.

**kasholkaTTS → Язык / Language** (в английском интерфейсе **Language**):

- **Как в macOS / System** — первый предпочитаемый язык macOS. Русский выбирается
  для `ru`, английский — для `en` и пока неподдерживаемых языков.
- **Русский** и **English** — явный выбор, независимый от языка системы.

Изменение применяется при следующем запуске. Приложение не закрывает окно и не
прерывает чтение; перед обычным выходом нужно самостоятельно сохранить нужный текст.
Выбор языка хранится в настройках самого приложения. У Beta отдельные настройки.
Системные настройки языка macOS не изменяются.

Переведены собственные кнопки, меню, подсказки, запуск, названия языков/регионов,
экспорт, диагностика, Beta и обновления. Имена голосов возвращает macOS; они не
переводятся и не подменяются. Пробная фраза зависит от языка голоса, а не интерфейса.
Текст редактора, имена файлов, голосовые ID и диагностические данные не переводятся.
Стандартные элементы системных окон и ошибки macOS могут оставаться на языке ОС.
Установщик начиная с 1.7.2 / 1.7.3 Beta сначала открывает выбор **Русский / English**
с кнопкой **Отмена / Cancel**. До выбора языка файлы установки не создаются и приложение
не меняется. Этапы, ошибки и финальное окно используют выбранный язык. Выбор относится
только к установщику, язык самого приложения меняется в его меню. Русский и английский тексты разделены
в функциях `message_ru` / `message_en` в `installer/Install kasholkaTTS.command`.
Для явного выбора при запуске из Терминала: `--lang ru` или `--lang eng` (`en` тоже
поддерживается) — это пропускает начальный выбор. В режиме `--update` нет ни выбора
языка, ни финального диалога; язык берётся из настройки приложения или macOS. Технический вывод команд
пишется в отдельный временный журнал: при ошибке показывается путь, при успехе журнал
удаляется. Сообщения системных утилит в журнале сохраняются в исходном виде.

## Как добавить язык

1. Создать `locales/<код>.json`, взяв за основу `locales/en.json`:

   ```json
   {
     "name": "Français",
     "messages": {
       "Читать": "Lire",
       "Аудио сохранено: {path}": "Audio enregistré : {path}"
     }
   }
   ```

2. Ключ — исходная русская строка, значение — перевод. Русские исходные строки
   являются базовым каталогом. Сохранять ведущие/конечные пробелы и `\n` у составных
   сообщений. Для новых сообщений с переменными использовать именованные параметры:
   `t('Аудио сохранено: {path}', { path: destination })`. Значения параметров не
   переводятся и не обрабатываются повторно как шаблон. Имена параметров должны совпадать.
3. Код файла — двухбуквенный код языка. Название `name` показывается в меню на самом
   языке. Новый каталог автоматически появится в меню после сборки. Если перевод
   отсутствует в дополнительном языке, используется английский, затем исходная строка.
4. Запустить сборку и тесты, проверить окна на Mac при масштабе 80%, 100% и 150%.

`src/localization.js` отвечает за выбор языка и перевод. `scripts/localization.py`
проверяет каталог и встраивает его вместе с функциями локализации в существующий
`src/kasholkaTTS.js` внутри ZIP. Поэтому обновлятор протокола 1 из версии 1.6 получает
все переводы без скачивания дополнительных ресурсов. Исходные JSON остаются в репозитории.
Никаких сетевых переводчиков и зависимостей нет.

Английский каталог должен покрывать все собственные строки интерфейса и известные
ошибки помощников: сборка останавливается при пропущенных/пустых переводах или
несовпадающих параметрах. Тест проверяет, что русские строки явно проходят через `t()`.

## Проверка на Mac

- На русском Mac первый запуск русский, на английском — английский.
- Выбор English → обычный выход → запуск: главное окно, About, меню, экспорт,
  диагностика, загрузка и обновления на английском.
- English → Русский и System: выбранная настройка сохраняется и применяется после запуска.
- Выбор языка во время чтения не меняет текст, выделение, голос, скорость и чтение.
- Русский голос произносит русскую пробную фразу и при английском интерфейсе.
- Проверить переключатель отдельно в Beta: выбор основной версии не переносится.
- Установить новый ZIP или обновиться из 1.6 после публикации: языки доступны без
  дополнительных файлов. Проверки настоящего AppKit выполняются только на Mac.
