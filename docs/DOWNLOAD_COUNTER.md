# Счётчик ручных скачиваний

Workflow `ZIP downloads` учитывает только опубликованные `*-macOS-manual-installer.zip`
основной версии и Beta. Служебные ZIP для автообновления, контрольные суммы и старые
общие архивы исключены. Бейдж показывает загрузки файлов, а не число установок/пользователей.

## Сброс на ноль

1. Откройте GitHub → Actions → ZIP downloads → Run workflow.
2. Выберите ветку `main`.
3. Отметьте «Сбросить счётчик и считать только новые скачивания» и нажмите Run workflow.
4. Дождитесь зелёного результата. В `badges/downloads.json` будет `message: "0"`.
   Бейдж догонит файл после обновления кеша; это не мгновенно.

Workflow сохранит текущие количества по ID каждого ручного ZIP в `badges/downloads-baseline.json`.
Последующие проверки вычитают этот снимок. Новые архивы учитываются с первого скачивания;
удаление старого архива не уменьшает результат остальных. Если во время сброса появятся
новые скачивания, следующий запуск уже покажет их.

Обычный Run workflow без галочки только обновляет число. Расписание — каждый час на 37-й минуте.
Не редактируйте `message` вручную: следующий запуск пересчитает его. Для возврата полного
числа ручных скачиваний удалите только `badges/downloads-baseline.json` и запустите workflow без галочки.
Это не вернёт смешанную статистику общих ZIP. Настоящий download_count GitHub не сбрасывается.
Проверочные скачивания ручных ZIP тоже считаются; сброс после проверки выпуска исключит их.
